# 🛡️ Tamizh SecureX

A smart and secure access control system developed using Raspberry Pi 5 to improve authentication, monitoring, and entry management.

Tamizh SecureX combines embedded systems and automation concepts to create a secure, reliable, and user-friendly access solution.

---

# 📌 Project Objective

Traditional access systems may lack flexibility, authentication strength, and proper tracking.

Tamizh SecureX aims to provide:

✔ Secure user verification  
✔ Controlled access management  
✔ Real-time monitoring  
✔ Digital logging of activities  

---

# 🚀 Features

## 🔐 OTP Verification
Generate and validate OTP for secure authentication.

## 👤 User Authentication
Allow only authorized users to access the system.

## 📋 Activity Logging
Record entry and exit information.

## ⚡ Fast Access Control
Provide quick and secure permission handling.

## 🖥 Monitoring System
Track system events and improve security visibility.
